Atomic / Harbor-style sidebar icon pack

Style:
- 24x24 SVG
- 2px outline stroke
- round line caps / joins
- white stroke for easy recoloring in Qt

Included:
home, discover, movies, shows, anime, live-tv, calendar,
library, addons, settings, search

Added for Atomic's own rail (same 24x24 / 2px / round-cap grid),
because the pack covers no row for them:
manga (open book), manhwa (webtoon strip), manhua (stacked
issues), games (gamepad), apps (launcher grid), websites (globe),
saved (bookmark), history (clock with a rewind arrow).

Qt tip:
If you need dynamic colors, load the SVG text and replace #FFFFFF
with your current normal / hover / active color before passing it
to QSvgRenderer, or pre-generate tinted QPixmaps and cache them.

These are original Lucide-inspired outline assets made for Atomic.
